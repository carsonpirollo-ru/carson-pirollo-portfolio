# Carson Pirollo — Personal Portfolio

A responsive personal portfolio for Carson Pirollo, a Rutgers finance student and founder of Pirollo & Co.

- **Live website:** https://carsonpirollo-ru.github.io/carson-pirollo-portfolio/
- **Public repository:** https://github.com/carsonpirollo-ru/carson-pirollo-portfolio

## Assignment requirements

- **Personal statement:** A one-sentence professional introduction in the About section.
- **Skills:** Financial modeling, product design and CAD, sourcing and negotiation, supply chain management, branding and e-commerce, and web design and SEO.
- **Projects:** Green Mat, Blue Mat, and Mhome, each with an image, a brief description, areas of contribution, and an Amazon listing or storefront link.

Green Mat is the original launched product. Blue Mat and Mhome are presented as product-development projects, without claiming that all three have shipped.

## Run locally

Open `index.html` in a browser, or serve this folder with:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a **public** GitHub repository and upload this folder’s contents to its root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**. Save.
4. Wait for the deployment, then open the live address displayed in Pages settings.
5. Submit the public repository URL and the live GitHub Pages URL.

All site links use relative local paths, so the site supports both a repository Pages URL and a user Pages URL without configuration. No dependencies, installation, or build step are required.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive styles
- `green-mat.jpg`, `blue-mat.jpg`, `mhome.png` — supplied product assets
- `.nojekyll` — serves the site as static files

Product imagery and branding belong to Pirollo & Co. The public site includes professional information and a business contact email; it does not include the source résumé, home address, phone number, supplier documents, or financial workpapers.
